## ✨ About the Project

**BikeCart** is a front-end web project designed to showcase bike-related content with a modern, user-friendly interface.

It focuses on:

- Simple and clean design
- Responsive layout
- Easy navigation
- Lightweight, fast-loading pages

---

## 🚀 Features

- 🏠 Attractive landing page
- 🚲 Bike showcase sections
- 📱 Responsive design for mobile/tablet/desktop
- 🎨 Styled with custom CSS
- ⚡ Fast and lightweight static website

## ⚙️ Getting Started

### Prerequisites

You only need a web browser (Chrome, Edge, Firefox, etc.)

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/amitmahato98/bikecart.git
   cd bikecart
   ```

2. Open `index.html` directly in your browser  
   **or** use VS Code Live Server for better development workflow.
